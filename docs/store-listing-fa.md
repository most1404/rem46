# راهنمای انتشار در کافه‌بازار و مایکت

> الزامات فروشگاه‌ها ممکن است عوض شود. پیش از ثبت، صفحهٔ راهنمای «پنل توسعه‌دهندگان» همان فروشگاه را بخوان؛ من از اینجا نتوانسته‌ام آن‌ها را بررسی کنم.

## قبل از انتشار (الزامی)
1. **کلید امضا:** کلید جدید بسازید و در GitHub Secrets بگذارید (مورد ۱). همان کلید برای همهٔ نسخه‌های بعدی و همهٔ فروشگاه‌ها باید ثابت بماند؛ اگر گم شود، نمی‌توانید به‌روزرسانی منتشر کنید.
2. **مخزن خصوصی** بماند و فایل کلید داخلش نباشد.
3. **آدرس به‌روزرسانی داخلی:** فایل `update/Updater.kt` به یک آدرس GitHub اشاره می‌کند که باید آدرس خودت باشد. بعضی فروشگاه‌ها به‌روزرسانی از بیرون فروشگاه را نمی‌پذیرند؛ برای نسخهٔ فروشگاه شاید لازم باشد آن را خاموش کنید و مجوز نصب بسته را بردارید.
4. **سیاست حریم خصوصی:** `docs/privacy-policy-fa.md` را کامل و روی یک آدرس عمومی بگذارید (مثلاً صفحهٔ GitHub Pages).
5. **تست دسترسی** به Supabase در ایران بدون VPN با چند اپراتور.
6. فایل **APK امضاشدهٔ release** از GitHub Actions (بخش Artifacts).

## متن پیشنهادی صفحهٔ فروشگاه
**نام:** یادآور شمسی
**توضیح کوتاه:** یادآور فارسی با تاریخ شمسی، زنگ هشدار و یادآورهای مشترک با خانواده و دوستان.

**توضیح کامل:**
یادآور شمسی یک برنامهٔ فارسی برای مدیریت کارها و یادآوری‌هاست.
- تاریخ شمسی کامل و فیلتر امروز، این هفته و این ماه
- زنگ هشدار دقیق، تأخیر و تکرار
- ویجت صفحهٔ اصلی با سه بخش: همه، شخصی و اشتراکی
- ثبت صوتی و جست‌وجو
- یادآورهای اشتراکی با گروه، کد دعوت و رمزنگاری یادآورها
- یادآورهای شخصی فقط روی گوشی شما می‌مانند
- قفل اثر انگشت و پشتیبان‌گیری

**دسته‌بندی پیشنهادی:** ابزارها / بهره‌وری
**کلمات کلیدی:** یادآور، تقویم شمسی، هشدار، کارهای روزانه، ویجت، یادداشت

## نکته برای بررسی فروشگاه
- مجوزهای حساس (زنگ دقیق، نمایش تمام‌صفحه، میکروفون، نصب بسته) را در توضیح فروشگاه با دلیلشان بنویسید.
- اطلاعات تماس و آدرس سیاست حریم خصوصی را آماده داشته باشید.
- برای هر نسخهٔ جدید، شمارهٔ نسخه (`versionName`) و یادداشت تغییرات را بنویسید.
